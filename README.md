A ranked board of pre-token protocols from the DefiLlama watchlist, each with an implied launch value and a concrete farming plan. Ships a static dashboard with a detail view for every protocol and a working filter — no network needed to browse it.

## Run it

```sh
node main.ts --input input/snapshot.json --output out
```
